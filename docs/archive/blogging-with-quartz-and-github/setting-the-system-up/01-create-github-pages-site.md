# Step 01 – Create a GitHub Pages site

## What you’ll do
1. Open GitHub in your web browser.
2. Click **New** → **Repository**.
3. Name the repository **`your‑username.github.io`** (replace `your‑username` with the name you use on GitHub, e.g., `natarslan`).
4. Keep the repository **public** and **do NOT** add a README, .gitignore or license – leave it empty.
5. Click **Create repository**.

## Why this matters
* **GitHub Pages** is a free service that turns a GitHub repository into a public website. By naming the repo `your‑username.github.io` GitHub knows this repo should be published at `https://your-username.github.io`.
* An **empty repository** gives us a clean place to push the files that Quartz will generate.

## Key terms explained
* **Repository (repo)** – a folder on GitHub that stores all the files for a project.
* **Public** – anyone on the internet can view the files and the website.
* **GitHub Pages** – a feature that automatically serves the contents of a repo as a website.

## What you’ll see after this step
* A new page at `https://github.com/your‑username/your‑username.github.io` showing an empty file list.
* The URL where your site will appear once we push content: `https://your‑username.github.io`.
