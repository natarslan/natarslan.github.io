## Where to put a new Markdown post

Put it anywhere under `posts/`.

Examples:

- `posts/photography/street-readers.md`
- `posts/travel-nature/winter-camping.md`

Folders become sections on the site.

## Recommended structure

- One topic folder per post:
  - `posts/travel-nature/winter-camping.md`
  - `posts/travel-nature/winter-camping/` (optional, if you want assets next to the post)

## Optional frontmatter

Quartz works fine without frontmatter, but adding a title is helpful:

```md
---
title: Winter camping
---
```
