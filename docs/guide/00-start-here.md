You have a Quartz blog.

Quartz turns Markdown files into a website and GitHub Actions publishes it to GitHub Pages when you push to `main`.

## The only 3 things you need to know

1. **Write Markdown in `posts/`**
2. **Put images/files next to the post or in `posts/attachments/`**
3. **To publish: `git commit` + `git push`**

## Quick: create your first post

1. Create a new file: `posts/my-first-post.md`
2. Add content:

   ```md
   ---
   title: My First Post
   ---

   Hello world.
   ```

3. Preview locally (see [[04-preview-locally]]).
4. Publish (see [[05-publish-to-github]]).
