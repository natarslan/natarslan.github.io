# Create the GitHub Pages repository

1. Visit https://github.com and sign in. If you do not have an account yet, create one at https://github.com/signup.
2. Click your profile avatar → `Your repositories` → `New`.
3. Set the repository name to `natarslan.github.io`. This exact name tells GitHub Pages to publish from the root of that repo.
4. Keep the repo **Public** and leave the README unchecked; we will bring our own files.
5. Press `Create repository`. Your empty Pages repo now lives at `https://github.com/natarslan/natarslan.github.io`.

Why this matters: GitHub Pages always looks for a repository named `<username>.github.io`. Creating it first means Quartz can deploy there later without extra routing rules.
