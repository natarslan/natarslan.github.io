# Clone the GitHub Pages repository locally

1. In Terminal, move to the folder where you keep projects, for example:
   ```bash
   cd ~/Desktop/starbase
   ```
2. Clone your empty Pages repo:
   ```bash
   git clone https://github.com/natarslan/natarslan.github.io.git
   ```
   Replace the URL with the SSH form (`git@github.com:natarslan/natarslan.github.io.git`) if you prefer SSH keys.
3. Enter the folder:
   ```bash
   cd natarslan.github.io
   ```

You now have a local workspace that will mirror whatever goes live at https://natarslan.github.io once we add Quartz.
