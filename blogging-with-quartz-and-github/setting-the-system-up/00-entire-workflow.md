# Quick Index of the Setup Steps

Below is a short, beginner‑friendly list of the numbered guide files you will find in the **`setting-the-system-up`** folder. Click each link to open the detailed step.

| Step | File | What you’ll learn |
|------|------|-------------------|
| 01 | `01-create-github-pages-site.md` | How to make a **GitHub Pages** site (no jargon needed). |
| 02 | `02-install-prerequisites.md` | Installing the tools (Node, npm, Git) that let you build the site. |
| 03 | `03-clone-repo.md` | Getting a local copy of the empty site repository onto your computer. |
| 04 | `04-add-quartz-starter.md` | Bringing the Quartz template files into your repository. |
| 05 | `05-install-node-dependencies.md` | Downloading the JavaScript packages Quartz needs. |
| 06 | `06-configure-site.md` | Setting the site title, URL, and basic options. |
| 07 | `07-connect-obsidian-content.md` | Linking your Obsidian notes to Quartz without copying files. |
| 08 | `08-preview-and-test.md` | Building the site locally and checking it looks right. |
| 09 | `09-authenticate-github.md` | How to let your computer talk to GitHub securely (PAT or SSH). |
| 10 | `10-push-and-deploy.md` | Sending your site to GitHub so the live page appears. |

Each file is written for a **complete beginner** – we explain every term (e.g., *repository*, *remote*, *push*) and show the exact commands you need to type.

---

Start with **Step 01** and work your way down the list. When you finish a step, commit the changes and move on to the next one.
