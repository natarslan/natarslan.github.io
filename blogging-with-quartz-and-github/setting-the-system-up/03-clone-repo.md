# Step 03 – Get a local copy of your site repository

## What you’ll do
1. Open a terminal (you already have one open).
2. Navigate to a folder where you keep your projects, e.g.:
   ```bash
   cd ~/Desktop/starbase
   ```
3. Clone the repository you created in Step 01 (replace `your‑username` with your GitHub name):
   ```bash
   git clone https://github.com/your-username/your-username.github.io.git
   ```
4. Change into the newly created folder:
   ```bash
   cd your-username.github.io
   ```

## Why this matters
* **Cloning** copies the remote repository to your computer so you can edit files locally.
* All future changes will be made in this folder and then sent back to GitHub.

## Key terms explained
* **Clone** – making a local copy of a remote repository.
* **URL** – the web address of the repository; the `https://` form works with a username/password or personal access token.
* **Folder** – a directory on your computer; `cd` changes the current folder.

## What you’ll see after this step
* A new folder named `your-username.github.io` appears inside `starbase`.
* Inside that folder you will see a few files (like `package.json`) – the site is ready to be customized.
